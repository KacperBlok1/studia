# Python (K. Lewandowski) – zaliczenie

> [!abstract] W skrócie
> Zaliczenie to **jednoosobowy projekt**, który pokazuje użycie podanych elementów Pythona. Prezentacja na **ostatnim wykładzie**, potem wgranie na Moodle (zakładka „Projekt zaliczeniowy").

## Co musi być w projekcie

| Element | Gdzie w notatkach |
|---|---|
| pętle | [[Python Lewandowski – moduł 2 (pętle, warunki, listy)]] |
| listy, krotki, ciągi znaków | moduł 2 i [[Python Lewandowski – moduł 3 (funkcje, słowniki, moduły)]] |
| słowniki | moduł 3 |
| funkcje, funkcje wbudowane | moduł 3 |
| generatory | moduł 3 |
| moduły i pakiety | moduł 3 |
| wyjątki | moduł 3 |
| obliczenia numeryczne | `math`, `random` (moduł 3) |
| operacje na plikach | [[Python Madej – sterowanie i pliki]] |
| klasy | moduł 3 |
| wyrażenia regularne | brak w materiałach – do doczytania |

## Forma projektu

Dowolna: aplikacja konsolowa, okienkowa, webowa albo projekt z analizy danych – byle użyć wszystkich elementów z listy.
